Read 03-design-system.md alongside the project PRD (docs/02-PRD.md). The specification defines identity, UI behavior, responsive rules, and component responsibilities. Explore every flow below to see those contracts in context.

SpoolIn is named after the spool that holds a length of film. Its promise: unspooling stories and discovering what’s behind them. Read the brand history.

One system: Cinema at night for dark mode and Film gallery for light mode, with shared components and one token authority.
